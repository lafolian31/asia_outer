## 백업·복구 검사

관리자 계정으로 메타데이터와 파일을 백업하고 별도 빈 로컬 서버의 새 Auth UUID에 대응시켜 복구했습니다. 최종 실행은 기록 28건·첨부 14개의 내용·파일 SHA-256·연결 계획·역할·활성 여부를 비교했습니다. 복구 후 타인 수정·비참여자 접근을 재검사하고, 비어 있지 않은 대상의 재복구 거부도 확인했습니다.

복구 도구가 Auth 비밀번호·로그인 토큰을 복원하는 것은 아닙니다. 계정 재생성·새 비밀번호·UUID 대응이 필요하며 원래 감사 목록은 manifest에서 보관합니다.

## 남은 제약·미검증

- **공개 배포 진행 중:** 실제 접속 주소는 아직 없습니다. 이후 사용자가 Supabase 설치와 Cloudflare/GitHub 연결을 진행했습니다. 최신 상태는 [배포 진행 상태](DEPLOYMENT_PROGRESS.md)에 별도로 기록하며, 위 검증 결과는 로컬 실행 기준입니다.
- hosted Supabase의 실제 RLS·Storage 설정과 공개 HTTPS 사이트는 연결 후 별도 검증해야 합니다. 로컬 기반은 PostgreSQL 17, Auth v2.180.0, Storage v1.28.2, PostgREST v13.0.7이며 hosted 서비스 버전과 완전히 같다고 보장하지 않습니다.
- 실제 Android/iPhone의 카메라 선택기·HEIC 변환·Safari PDF 처리, 실제 두 기기의 네트워크 동기화는 미검증입니다. 격리된 Chromium과 모바일 화면 크기 검증만 완료했습니다.
- 사진은 JPG·PNG·WebP만 지원합니다. PDF 외 한글·엑셀·워드 내부 미리보기는 제공하지 않고 원본을 다운로드합니다.
- 인터넷 연결을 전제로 합니다. 열린 창의 저장 실패 입력은 보존하지만 새로고침·앱 종료 후 미저장 초안 복원은 없습니다.
- 목록은 조회 시 서버 자료를 동기화하며 새로고침·탭 복귀·주기 조회를 사용합니다. 실시간 동시 편집 기능은 아닙니다. 처음부터 모든 기록을 읽으므로 대규모 장기 운영에서는 서버 측 검색·집계·페이지 처리가 필요합니다.
- 파일 900MB 앱 제한, 사진 2MiB·문서 10MiB·기록당 10개, ZIP 백업 100MB 제한이 있습니다. 큰 백업은 PC 명령을 사용합니다. 휴지통도 용량을 차지합니다.
- 본문과 파일 업로드는 부분 성공할 수 있습니다. 이 경우 실패와 재시도를 안내하며 관리 화면에서 미완료 첨부를 복구·정리할 수 있습니다.
- 자동 이메일 초대·비밀번호 재설정·예약 원격 백업은 제공하지 않습니다. 계정 생성은 소유자가 관리 도구에서 수동으로 합니다.
- 무료 한도·휴면·중단 조건이 있습니다. 무료 영구 운영을 보장하지 않습니다. Cloudflare 전체 최신 약관의 직접 확인은 이 환경에서 불가했으며 공개 배포 전에 소유자가 확인해야 합니다.
- 이미 열람·다운로드한 자료의 사본을 회수할 수는 없습니다. 앱은 공개 다운로드 주소·서명 공유 링크를 생성하지 않습니다.

유료 기능·서비스를 활성화하지 않았으며 외부 초대 메시지를 전송하지 않았습니다. 개발 환경의 `install_script`와 `start_skill`은 재사용 초안으로 저장했으며, 초안 저장이 웹앱 공개 배포나 새 작업 복원 검증을 의미하지 않습니다.

### 안녕동 실제 농장 좌표 적용

사용자가 제공한 네이버 지도 링크의 lat=37.2040072, lng=127.0192951을 확인해 farmWeatherLocation에 반영했다. 주소는 경기도 화성시 병점구 안녕동 10-36으로 정정했다. 좌표 확인 대기를 해제하여 실제 브라우저 API 요청을 활성화했다. 유료 기능·키·DB 변경 없음.

단위 검증 10건, build 및 날씨 브라우저 검증 3건 통과. PC·모바일 요청의 latitude/longitude가 사용자 지도 좌표와 일치하는지 검사했다. 결측 좌표 검증은 시험용 모듈 응답만 null로 바꾸어 확인했다. 응답은 모의 데이터이며 실제 운영 날씨 수신 확인과 구분한다. 실제 좌표의 Open-Meteo API 요청도 환경 프록시 403으로 차단되어 실시간 값 수신은 사용자 사이트에서 확인이 필요하다.

## 글자 확대와 읽기 편의 개선

기본 본문 root 18px, 기존 고정 px 글자 크기를 rem으로 전환하여 작은 안내 글씨도 기본 최소 약 14px로 확대했다. 본문·기록 내용·입력값은 더 크게 표시하고 옅은 회녹색 글씨를 진하게 조정했다. 로그인·참여 승인·앱 상단에 글자 크기(기본 18/크게 21/아주 크게 24px 본문 기준) 선택을 제공한다. 브라우저 localStorage에 기기별 선택을 저장하며 불가한 경우 현재 화면 변경은 유지한다. 입력·버튼 최소 높이 48px, 체크박스 24px, 키보드 초점 테두리, 작은 화면의 확장 메뉴 가로 스크롤과 큰 글자에서 한 열 배치를 적용했다. 기존 데이터·권한·DB는 변경하지 않는다.

`npm run test:e2e` 전체 31건 통과. 신규 가독성 검증 4건에는 320/390/1440px, 기본·아주 크게 전 메뉴 가로 넘침 없음, 편집 화면의 입력 글씨 18px 이상과 대화상자 폭, 선택의 새로고침 유지, 크게 전환, 로그인 전 설정 복원, 키보드 열기와 저장소 차단 시 크기 변경을 포함한다. 기존 사진·파일·권한·댓글·계획·선택 기록·날씨 검증도 통과했다. 단위 검증 10건, build, formatter 통과. 모바일 기본 화면을 시각적으로 확인했다. 실제 40~60대 참여자의 사용성 평가나 모든 보조공학 환경의 적합성 인증을 뜻하지 않는다. 운영 배포 후 실제 기기 확인은 남는다.

### 조금 작게 및 계정별 마지막 크기 복원

‘조금 작게’(본문 기준 16px)를 추가하고 시작 시 저장값 복원 허용 목록에 포함했다. 로그인 상태에서는 `farm-text-size:<userId>`에 마지막 선택을 저장하고, 로그인/재접속 때 해당 계정 값을 먼저 복원한다. 로그인 전 화면은 기존 기기별 키 `farm-text-size`를 사용한다. 별도 서버 저장 없이 같은 브라우저에서 계정별 값을 구분하며 다른 기기 동기화는 하지 않는다. 저장소 차단·삭제 시 저장 유지가 제한된다.

가독성 브라우저 검증 5건 통과: 기존 크기/320·390·1440px 전 메뉴, 로그인 전 복원·키보드·저장소 차단, 16px 선택 후 새로고침, A=16px/B=24px로 로그아웃·재로그인하여 각각의 마지막 설정 복원 및 선택 표시 확인. build 및 formatter 통과. DB·유료 기능 변경 없음.

## 사이트맵 메뉴

공통 메뉴 정의를 `src/lib/navigation.ts`로 모아 기존 메뉴와 사이트맵에서 재사용했다. 농장 관리 다음에 사이트맵을 추가하고 농장 이름 아래 메뉴·주요 기능을 카드와 하위 목록으로 표시한다. 메뉴 제목을 누르면 기존 navigate를 사용해 이동하며, 사이트맵 자체는 현재 화면으로 표시한다. 농장 관리 항목은 기존과 같이 관리자에게만 표시한다. 사이트맵에 작성 버튼이나 새 권한을 부여하지 않는다.

## 농장계획 필터를 통합 찾기로 정리

목표 연도·예정 월·계획 상태·작성자 선택 UI와 숨은 연도/월/상태 필터 상태를 제거했다. 농장계획 메뉴를 열면 모든 연도가 표시되며 기존 가까운 일정순 정렬을 유지한다. 검색은 제목·내용·목표 연도·기간에 포함된 월·실행일·계획 자체 상태·작성자·담당자·완료 처리자·작물·장소·결과와 연결된 기록/첨부 이름을 대상으로 한다. 띄어쓰기 검색은 항목 간 AND, 상태 단어는 계획 자체의 상태를 기준으로 해 연결 일지의 상태가 섞이지 않게 했다. 미완료는 미실행/진행중이다.

홈 올해 계획은 `목표연도:현재연도`를 보이는 검색창에 넣어 이동한다. 목표 연도가 다르지만 실행일이 올해인 계획을 잘못 집계하지 않는다. CSV와 접힌 요약은 현재 검색 결과를 사용한다. 계획 작성 양식·기존 데이터·사진·권한은 변경하지 않았으며 DB 마이그레이션은 없다.

검증: 단위 12건, 전체 브라우저 37건, build, formatter 통과. 새 브라우저 검증은 PC/모바일에서 선택칸 0개·검색 입력 1개, 이전/현재/다음 연도 기본 조회, 월 범위·작성자·담당자·상태·결과·연결 일지 검색, 필터 해제, CSV 결과, 검색된 계획 요약, 가까운 일정순 보존을 확인한다. 기존 홈 올해 계획 수와 이동 결과 일치 및 모든 기존 작성/권한/첨부 검증도 통과했다. 검증은 격리된 로컬 환경이며 운영 사이트 반영은 자동 배포 후 확인이 필요하다.

## 운영·교류 필터를 통합 찾기로 정리

목록의 날짜 범위·연결 계획·활동 분류·작성자 선택 UI와 관련 숨은 필터 상태를 제거했다. 검색창 하나에서 제목/내용/날짜 별칭/활동 분류/작성자·참여자 이름/연결 계획명·목표 연도/첨부파일 이름을 찾으며 CSV는 그대로 현재 결과를 내보낸다. 농작업과 운영 기록은 기존 record_type 구분을 유지하고 자료함의 분류·작성자 필터는 보존했다. 활동 작성 필드, 기존 데이터·사진·문서·권한·DB는 변경하지 않는다.

PC·모바일 신규 브라우저 검증 2건 통과: 날짜·분류·작성자·참여자·계획·실제 저장한 파일 이름으로 찾기, 복합 검색, 미연결 계획, 농작업 기록 혼입 없음, CSV 내용과 검색 결과 일치, 검색 해제·열람자 쓰기 버튼 없음·페이지 가로 넘침 없음. 기존 선택형 기록 브라우저 검증 4건도 활동 분류 검색을 사용하는 방식으로 갱신해 통과했다. 단위 12건, build, formatter 통과. 실제 운영 배포 후 화면 확인은 별도다. 추가 SQL·유료 기능 없음.

## 공동체 이름 상단 복원

모바일에서 기존 사이드바 브랜드가 숨겨져 공동체 이름이 보이지 않던 원인을 확인했다. 모든 로그인 화면의 공통 상단에 ‘함께그린’ 홈 링크를 추가해 각 메뉴에서 이름을 볼 수 있게 했다. 작은 화면에서는 이름과 도구를 줄바꿈하고 글자 크기 패널의 위치를 맞췄다. 320px 아주 큰 글자 검증 중 긴 휴지통 항목의 버튼이 화면을 넘는 것도 발견해 작은 화면에서 제목/버튼을 줄바꿈하도록 보완했다. 저장된 농장 이름·데이터·권한은 변경하지 않는다.

브라우저 8건 통과: 320/390/1440px 모든 메뉴에서 상단 이름 표시 및 이름 클릭으로 홈 이동, 기존 가독성·계정별 크기 복원 5건 포함. build 및 formatter 통과. 추가 SQL·유료 기능 없음. 운영 화면은 자동 배포 반영 후 새로고침 필요.
