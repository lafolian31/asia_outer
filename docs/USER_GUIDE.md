# 함께그린 간단 사용 안내

접속 주소는 https://asia-outer.pages.dev/ 입니다. 현재 실서버 검수를 진행 중입니다. 초기 관리자의 앱 로그인은 Supabase Authentication → Users에서 직접 생성한 계정의 이메일·비밀번호를 사용합니다. Cloudflare 계정이나 DB 비밀번호와는 별개이며, 공통 기본 비밀번호는 없습니다.

## 관리자: 첫 설정과 참여자 초대

최초 서비스 소유자는 [배포 안내](DEPLOYMENT.md)에 따라 본인을 관리자 계정으로 지정합니다. 앱의 **농장 관리 → 농장 설정**에서 농장 이름·구역·작물을 바꿉니다. 쉼표로 여러 구역·작물을 구분할 수 있습니다.

초대는 자동 메일을 보내지 않는 절차입니다.

1. 서비스 소유자가 Supabase → Authentication → Users → **Add user**에서 대상자의 개별 이메일·임시 비밀번호로 계정을 생성합니다. 확인 완료 상태를 사용합니다. 비밀번호를 채팅·소스·공용 문서에 기록하지 않습니다.
2. 앱의 **농장 관리 → 참여자 초대 코드 만들기**에서 같은 이메일과 초기 권한을 선택합니다. 보통 `참여자`, 보기만 할 사람은 `열람자`입니다.
3. 생성된 코드, 실제 접속 주소, 계정 안내를 대상자에게 안전한 방법으로 직접 전달합니다. 본 앱은 전송하지 않습니다. 코드는 해당 이메일 계정에만 유효하고 7일 이내 한 번 사용합니다.
4. 대상자가 로그인한 후 표시 이름과 초대 코드를 입력합니다. 로그인했다는 사실만으로는 농장 자료에 접근할 수 없습니다.
5. 첫 로그인 후 화면 위 **열쇠 아이콘 → 비밀번호 변경**으로 본인만 아는 12자 이상 비밀번호를 설정합니다.

이메일 자동 재설정 기능은 없습니다. 잊어버린 비밀번호는 소유자가 Supabase 관리 도구로 재설정하고 안전하게 전달합니다. 이후 외부 SMTP를 도입할 때는 무료 조건·발송 제한을 확인해야 합니다.

**농장 관리 → 참여자와 권한**에서 관리자·참여자·열람자로 바꾸거나 접근을 해제할 수 있습니다. 마지막 관리자는 해제할 수 없습니다. 탈퇴자의 기존 기록 작성자 표시는 유지됩니다. 재참여는 새 초대 코드를 쓰는 대신 관리자가 접근 복구를 합니다.

## 작업자: 일지와 첨부파일

1. **농작업일지 → 농작업 기록하기**에서 작업을 선택합니다. 날짜는 오늘, 제목은 작물·작업으로 자동 입력되며 수정할 수 있습니다. 메모는 선택 사항입니다.
2. 구역·작물과 관련 계획은 선택 항목입니다. 계획을 선택하지 않으면 `계획 외 작업`입니다.
3. **사진·파일 추가**에서 휴대전화의 사진 선택기를 엽니다. 기기에 따라 카메라 촬영 옵션을 선택할 수 있습니다. 카메라 옵션이 없으면 카메라 앱에서 촬영한 후 사진을 선택합니다.
4. **저장하기**가 끝난 후 목록에서 확인합니다. 다른 참여자는 새로고침하거나 화면으로 돌아와 같은 자료를 봅니다.
5. 상세 화면의 **수정하기 / 휴지통으로**는 본인 기록과 관리자에게 표시됩니다. 삭제된 기록은 관리자가 복원합니다.

사진은 JPG·PNG·WebP를 지원하고 긴 변 1,600px의 JPEG로 압축합니다. HEIC는 지원하지 않으므로 휴대전화에서 JPG로 변환하거나 카메라의 호환 형식을 사용하세요. 기록당 첨부 최대 10개, 압축 사진 2MiB, 문서 10MiB입니다. 위치 등 원본 EXIF 정보 보관을 목적으로 하는 기능은 아닙니다.

저장 실패·인터넷 단절 때 입력창을 닫지 마세요. 입력을 그대로 두고 연결 후 재시도합니다. 파일 일부만 실패했다면 안내에 따라 남은 파일을 저장합니다. 페이지를 새로고침하거나 닫으면 미저장 입력이 사라질 수 있습니다. 다른 사람이 먼저 수정했다는 메시지가 나오면 본인의 내용을 별도 메모한 뒤 최신 기록을 다시 열어 반영합니다.

## 농작업일지에서 빠르게 기록하기

농작업일지 메뉴의 ‘농작업 기록하기’ 버튼으로 시작합니다. 홈에는 기록 작성 버튼을 두지 않습니다. 대분류 → 세부작업을 고르고 작물을 선택하면 제목이 자동 생성됩니다. 작업 날짜는 오늘이며 수정할 수 있습니다. 메모·사진·계획 연결은 필요한 경우만 추가합니다. 농작업일지의 ‘빠른 기록 도구’를 펼쳐 ‘사진부터 기록’을 누르면 사진 선택기가 열리며 분류·메모 없이도 저장 후 나중에 보완할 수 있습니다.

자주 한 작업 버튼은 본인이 기록한 작업을 기준으로 표시합니다. 기록이 없을 때는 관수·제초·수확·생육 관찰을 바로 선택할 수 있습니다. 최근 선택한 작물·작업 장소는 같은 계정의 해당 기기에서 다음 입력 때 활용합니다. 기존 일지 상세의 ‘이전 작업 복사’는 오늘 날짜의 새 기록을 만들며 사진·댓글은 복사하지 않습니다. 자동 입력한 제목도 수정할 수 있습니다.

홈 요약 숫자를 누르면 올해 계획·운영 기록·자료·농작업일지 목록으로 이동합니다. 완료·미완료 집계는 농장계획의 ‘계획 상태·결과 요약 보기’를 펼쳐 확인할 수 있습니다.

## 농장계획과 실행 기록

1. **농장계획 → 계획 세우기**에서 목표 연도·예정 기간·내용을 입력합니다.
2. 작업자는 일지에 해당 계획을 연결합니다. 다른 사람이 만든 계획에도 본인 일지를 연결할 수 있습니다.
3. 일지를 연결한 것만으로 완료되지는 않습니다. 계획 작성자 또는 관리자가 상태를 `완료`로 바꾸면서 **실제 실행일과 결과 요약**을 입력합니다. 처리자와 시각은 자동 기록됩니다.
4. 계획 상세에서 실행 결과와 연결 일지·사진을 함께 봅니다. 다른 연도에 실행된 일지도 연결됩니다.
5. `보류`, `취소`, `계획 외 작업`은 완료 건수로 집계하지 않습니다. 농장계획은 검색어가 없으면 모든 연도를 표시하며, 날짜·목표 연도·상태 등은 검색창에서 찾습니다. 일지는 실제 작업 날짜를 기준으로 조회합니다.

## 자료 공유

**자료함 → 자료 올리기**에서 제목·분류·설명과 파일 또는 http/https 링크를 등록합니다. 사진·PDF·PPT·엑셀·워드·한글·TXT·CSV를 지원합니다. 사진은 화면에 표시하고 PDF는 브라우저 보기가 가능합니다. 그 외 문서는 원본 다운로드 후 해당 프로그램에서 엽니다. 비공개 자료 파일은 내려받기 요청마다 농장 권한을 검사합니다.

공유 링크는 외부 사이트의 링크입니다. 그 사이트의 접근 권한은 해당 서비스가 관리합니다. 농장 기록을 읽을 수 있는 사람에게만 보여도 외부 링크의 공개 범위가 바뀌지는 않습니다.

## 백업·복구

- 일반 목록의 **CSV**는 현재 검색 결과를 저장합니다. 관리자 **농장 관리 → CSV 내려받기**는 휴지통을 포함한 기록 목록을 저장합니다. 한글·날짜를 위해 UTF-8 BOM 형식을 사용합니다.
- **전체 백업 ZIP**은 기록·설정·참여자 역할·감사 목록과 첨부파일을 함께 저장합니다. 비밀번호·로그인 토큰·초대 코드 해시는 포함하지 않습니다. ZIP은 전체 파일 합계 100MB 이하에서 제공됩니다.
- 백업할 때 참여자에게 잠시 편집 중지를 알리고 최신 목록에서 실행하세요. 백업 중 변경을 발견하면 실패로 표시하므로 다시 실행합니다. 내려받은 백업을 개인 관리 장치와 별도 보관 장소에 이중 보관합니다.
- 100MB를 넘으면 PC에서 `scripts/backup.mjs`를 사용합니다. 관리자 계정으로 인증하며 큰 파일을 하나씩 내려받습니다. 예시는 아래와 같습니다. 환경변수 파일은 Git에서 무시되는 안전한 파일로 보관하고 공유하지 않습니다.

  ```bash
  # .env.backup에 프로젝트 URL·공개 키·관리자 이메일·비밀번호를 안전하게 설정
  node --env-file=.env.backup scripts/backup.mjs backups/2026-10-17
  ```

  필요한 변수 이름: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `FARM_EMAIL`, `FARM_PASSWORD`. 스크립트에는 값을 넣지 않습니다. 대상 폴더는 새 이름이어야 하며 부모 폴더를 먼저 만듭니다.

- CSV만으로 사진·권한까지 복구할 수는 없습니다. 파일을 포함하는 ZIP 또는 스크립트 백업을 보관하세요. 무료 플랜에는 본 앱의 자동 원격 백업 예약이 없습니다.

복구는 서비스 소유자/개발자가 **별도의 빈 프로젝트**에 수행합니다.

1. 백업 ZIP이라면 안전한 로컬 폴더에 풉니다. `manifest.json`과 `files/`가 있어야 합니다.
2. 새 Free 프로젝트에 앱 마이그레이션을 적용합니다. 아직 초기 관리자 SQL은 실행하지 않아 `members/entries/assets`가 비어 있어야 합니다.
3. 백업에 있는 참여자들의 Auth 계정을 새 프로젝트에 다시 생성합니다. 비밀번호는 백업하지 않으므로 새로 설정합니다. 이전 UUID를 키, 새 UUID를 값으로 하는 `user-map.json`을 만듭니다. 이전 참여자·비활성 계정도 기존 기록의 작성자 연결을 위해 대응시킵니다.
4. 새 프로젝트의 `SUPABASE_URL`과 **서버 전용** `SUPABASE_SERVICE_ROLE_KEY`를 안전한 환경변수로 공급하고 다음 명령을 실행합니다. 이 키를 프런트엔드·채팅·소스에 넣지 않습니다.

   ```bash
   node --env-file=.env.restore scripts/restore.mjs BACKUP_FOLDER user-map.json --empty-target-confirmed
   ```

5. 복구 도구는 비어 있지 않은 대상을 거부하고, 파일 크기·계정 대응과 스크립트 백업의 SHA-256을 확인합니다. 계정 매핑 후 기록·계획 연결·파일·역할을 복원합니다. 원래 감사 이력은 백업의 manifest에 남기고 새 DB에는 복구 작업 감사가 기록됩니다.
6. 두 계정으로 기록·사진·권한을 점검하고 마지막 관리자·열람자·접근 해제 설정을 확인한 뒤 화면의 공개 설정을 새 프로젝트로 연결합니다.

복구는 여러 서비스에 걸친 순차 작업으로, 중간 실패 시 전체 자동 롤백을 하지 않습니다. 운영 프로젝트를 덮어쓰지 말고 별도 빈 프로젝트에서 원인을 해결한 뒤 다시 복구하세요. 소유자가 보관한 원본 백업은 수정하지 않습니다.

## 자료함 분류 늘리기

관리자는 **농장 관리 → 자료함 분류 관리**의 ‘사용할 분류’에 한 줄에 하나씩 분류를 입력하고 ‘분류 저장’을 누릅니다. 예를 들어 일반, 교육, 회의록을 각각 다른 줄에 입력할 수 있습니다. 최대 100개, 이름은 50자까지입니다. 자료를 올릴 때 분류를 선택하고, 자료함의 분류 필터로 찾아볼 수 있습니다.

목록에서 이름을 바꾸거나 빼도 기존 자료의 분류는 그대로 유지되며 검색할 수 있습니다. 기존 자료의 분류까지 바꾸려면 작성자 또는 관리자가 해당 자료를 수정합니다. 파일과 자료가 자동으로 삭제되거나 다른 분류로 이동하지 않습니다. 분류 목록도 파일 포함 백업에 저장됩니다.

‘데이터베이스 업데이트가 필요합니다’가 보이면 운영자가 추가 마이그레이션 `202610180001_resource_categories.sql`을 실행해야 합니다. 이전 자료함 기능은 계속 사용할 수 있습니다.

## 농작업일지·자료함의 감정표현과 댓글

농작업일지나 자료를 눌러 상세 화면을 열면 첨부파일 아래에 ‘감정표현’과 ‘댓글’이 있습니다. 참여자와 관리자는 좋아요·사랑해요·웃겨요·놀람 중 하나를 선택할 수 있습니다. 같은 표현을 다시 누르면 취소되고, 다른 표현을 누르면 변경됩니다. 한 사람당 한 기록에 하나만 선택할 수 있습니다.

댓글은 5,000자까지 작성할 수 있습니다. 본인 댓글은 수정·삭제할 수 있고, 관리자는 전체 댓글을 관리합니다. 기록 작성자라는 이유만으로 다른 사람의 댓글을 수정·삭제할 수는 없습니다. 열람자는 감정표현과 댓글을 보기만 합니다. 댓글의 링크·HTML 문자는 일반 글자로 표시됩니다.

다른 사람의 변경은 상세 화면의 ‘댓글 새로고침’으로 바로 확인하거나, 화면이 보이는 동안 최대 약 30초 간격으로 반영됩니다. 새로고침 도중 작성 중인 댓글은 유지됩니다. 작성 실패 시 입력을 보존하므로 연결을 확인한 뒤 다시 등록하세요. 브라우저 자체를 새로고침하면 저장하지 않은 입력은 사라집니다.

기록을 휴지통으로 옮기면 댓글·감정표현도 일반 참여자에게 숨겨지고, 관리자가 기록을 복원하면 함께 돌아옵니다. 기록 영구 삭제 시 함께 삭제됩니다. 댓글 삭제는 화면에서 숨기는 방식이며 관리자 백업에는 이력이 포함될 수 있습니다. 파일 포함 ZIP과 PC 백업 모두 댓글·감정표현을 포함합니다. 기존 백업에 해당 항목이 없으면 빈 목록으로 복구합니다.

추가 SQL 적용 전에는 기존 기록을 계속 열 수 있고 기능 업데이트 안내가 표시됩니다. 감정표현과 댓글은 별도의 유료 서비스 없이 기존 Supabase를 사용하며, 데이터베이스 사용량에는 포함됩니다.

## 농작업 분류와 조회

농작업일지에는 재배준비·심기, 물·양분 관리, 생육관리, 잡초·병해충, 수확·수확 후, 시설·환경, 관찰·점검, 기타 농작업 대분류가 있습니다. 세부작업 버튼을 누르거나 직접 입력할 수 있습니다. 관리자는 **농장 관리 → 농작업 선택 목록 관리**에서 모든 대분류의 세부작업을 추가·수정할 수 있습니다. 기존 기록의 작업 이름은 자동 변경하지 않습니다.

새 작물은 기록 입력의 ‘새 작물 이름 → 작물 등록’으로 공유 목록에 추가합니다. 작업 장소는 관리자가 등록한 농장 구역에서 선택합니다. ‘작업량·참여자 추가’를 펼치면 필요할 때만 작업량·단위·참여자를 기록합니다. 참여자 선택이 그 사람에게 수정 권한을 주지는 않으며 작성자와 관리자만 기록을 수정합니다.

농작업일지 조회는 찾기 입력칸 하나를 사용합니다. 제목·메모·작성자·참여자·작물·장소·대분류·세부작업·날짜·작업량·연결 계획명·첨부파일 이름을 입력할 수 있습니다. ‘들깨 제초’처럼 띄어 쓰면 모든 단어가 포함된 기록을 찾습니다. 날짜는 2026-10-20, 2026.10.20, 2026/10/20, 20261020 또는 2026년10월20일처럼 입력할 수 있습니다. 작물 이름으로 검색하면 재배이력을 볼 수 있고 ‘분류 미지정’으로 기존 미분류 일지를 찾을 수 있습니다. 기존 일지의 분류를 임의로 추정해 넣지 않습니다.

## 운영·교류와 계획 연결

운영·교류 메뉴에서 회의·운영, 교육·견학, 행사·교류, 판매·홍보, 나눔·봉사, 자재·행정 중 분류를 선택하고 날짜·제목·내용·사진을 남깁니다. 참여자와 관련 계획은 선택 사항입니다. 농작업과 메뉴만 분리되어 있으며 첨부·댓글·감정표현·권한·백업은 공통으로 적용됩니다.

농장계획 상세에서 ‘관련 농작업 기록하기’ 또는 ‘운영·교류 기록하기’를 누르면 해당 계획이 미리 연결됩니다. 계획 내용을 실제 작업 메모로 다시 쓰지 않아도 됩니다. 연결된 모든 기록은 활동 날짜순으로 표시되며 다른 연도 기록도 포함합니다. 계획에 없는 작업은 계획을 선택하지 않고 자유롭게 저장합니다.

## 농작업일지의 복수 선택

대분류 버튼을 여러 개 누르면 각각의 세부작업 목록이 나타납니다. 세부작업도 여러 개 선택하며 같은 버튼을 다시 누르면 해제합니다. 대분류를 해제하면 그 분류의 선택 작업만 해제되고 다른 분류의 작업은 유지됩니다. 각 대분류에서 직접 입력한 작업도 ‘작업 추가’로 여러 개 넣을 수 있습니다.

‘작물’, ‘작업 장소’, ‘관련 농장계획’을 펼쳐 필요한 항목을 체크합니다. 참여자와 사진도 기존처럼 여러 개를 추가할 수 있습니다. 작업 날짜는 일지 한 건의 날짜 하나로 유지합니다. 작물과 작업의 전체 선택값으로 제목을 만들며 직접 수정한 제목은 유지합니다. 여러 계획에 연결한 일지는 각 계획 상세에 동일한 기록 하나로 표시되며 사진을 중복 저장하지 않습니다.

복수 선택은 상세·통합 찾기·이전 작업 복사·최근 작물/장소·CSV·백업에 반영됩니다. 기존 단일 기록은 그대로 표시하고, 수정할 때 기존 선택값이 체크됩니다. 분류 없이 직접 입력했던 세부작업도 별도 ‘기존 세부작업 · 분류 미지정’에 보존하며 임의의 대분류를 붙이지 않습니다. 일반 참여자는 본인 기록, 관리자는 전체 기록만 수정하는 기존 권한을 유지합니다.

복수 선택 기능은 운영자가 `202610200001_multi_recording.sql`을 적용한 뒤 활성화됩니다. 그 전에는 기존 단일 선택으로 계속 작성할 수 있습니다.

농작업일지·운영·교류·자료함 모두 사진과 문서를 함께 첨부할 수 있습니다. PDF·PPT·엑셀·워드·한글·TXT·CSV를 지원하며 사진과 파일을 합쳐 기록당 최대 10개입니다. 사진은 압축 후 장당 2MB, 문서는 파일당 10MB까지 저장합니다. 상세 화면에서 파일을 내려받고 PDF는 보기 버튼으로 열 수 있습니다. 첨부 권한은 본인 기록 또는 관리자에게 있으며 열람자는 내려받기만 가능합니다.

농장계획 목록은 오늘을 포함하는 일정과 다가오는 일정을 먼저 보여줍니다. 앞으로 시작하는 일정은 시작일이 가까운 순서이며, 종료일이 지난 일정은 뒤에서 최근 종료일 순서로 표시합니다. 종료일이 오늘인 계획은 지난 일정에 포함하지 않습니다. 홈의 다가오는 계획도 같은 정렬 기준을 사용합니다.

## 영농정보

로그인 후 **영농정보** 메뉴에서 기상청 날씨누리·흙토람·농사로·농업기상재해 조기경보시스템을 찾을 수 있습니다. 파종·심기, 물·양분 관리, 병해충·방제, 수확, 시설·재해 대비를 선택하거나 검색어를 입력하면 관련 사이트 카드가 표시됩니다. ‘활용 방법’을 펼쳐 안내를 보고 ‘사이트 열기’로 공식 사이트를 새 탭에서 엽니다. 검색은 함께그린에 정리한 사이트 안내를 대상으로 하며 외부 사이트의 전체 문서를 검색하지 않습니다.

기상·토양·재해 수치를 함께그린에 실시간으로 가져오지 않습니다. 외부 서비스에서 농장 지역·필지·작물과 정보 시각을 확인하세요. 맞춤 기능은 해당 사이트 가입·농장 등록 및 지원 지역 조건이 적용될 수 있습니다. 외부 사이트 이용정보를 함께그린 계정에 자동 저장하지 않습니다. 모바일 하단 메뉴가 화면을 넘으면 좌우로 이동해 영농정보·농장 관리를 선택할 수 있습니다.

영농정보의 **지역·교육**에서 [용인시 농업기술센터](https://www.yongin.go.kr/atc/index.do)의 교육·공지·영농 상담 안내를 찾을 수 있습니다. **가격·판매**에서 [농산물유통정보 KAMIS](https://www.kamis.or.kr/customer/main/main.do)를 열어 품목별 도매·소매 가격을 확인하세요. 날짜·지역·품종·등급·단위가 같은 조건인지 확인해야 하며 조사 가격과 실제 농장 판매가격은 다를 수 있습니다. ‘용인’, ‘농산물 가격’, ‘KAMIS’ 등으로도 검색할 수 있습니다.

## 홈 농장 날씨

홈 제목 오른쪽(작은 화면은 제목 아래)에 경기도 화성시 병점구 안녕동 10-36의 날씨 카드를 표시합니다. 농장 소유자가 제공한 네이버 지도 링크의 위도 37.2040072, 경도 127.0192951을 사용합니다.

연결 후 기온(°C), 상대습도(%), 풍속(m/s)·풍향, 일조(분)를 표시합니다. Open-Meteo 기상모델 추정치이며 현장 관측값이 아닙니다. 일조는 현재 분의 측정값이 아니라 직전 정시까지 1시간의 예보 일조시간(초를 분으로 환산)입니다. 한국 시각의 기준 시각을 함께 표시합니다. 화면을 보고 있는 동안 약 15분 간격으로 갱신하고, 같은 탭의 최근 응답을 캐시합니다. 오류 시 이전 자료임을 명시하거나 값 대신 —를 표시합니다.

Open-Meteo 무료 API는 비상업 용도 조건입니다. 상업 서비스로 전환한다면 제공 조건을 다시 확인해야 하며 유료 기능은 자동 활성화하지 않습니다. 키·유료 구독·Cloudflare Functions·DB 변경이 필요하지 않습니다. 날씨 요청에는 농장 좌표만 전달하고 사용자 계정이나 기기 위치는 전달하지 않습니다.

## 글자를 편하게 보기

기본 본문은 18px 수준으로 표시하며, 작은 안내 글씨와 입력 항목도 함께 키웠습니다. 로그인 화면과 로그인 후 화면 상단의 **글자 크기**를 눌러 **조금 작게 / 기본 / 크게 / 아주 크게**를 선택하세요. 본문 기준 16 / 18 / 21 / 24px이며 제목·버튼·설명도 함께 확대합니다. 로그인한 계정별 마지막 선택을 해당 브라우저·기기에 저장해 재접속 때 자동 적용합니다. 같은 PC를 다른 계정이 사용해도 각자의 선택을 복원합니다. PC와 휴대전화에서는 각각 한 번 설정하면 되며 다른 기기로 자동 동기화하지 않습니다. 저장소 사용이 차단된 환경에서는 이번 화면에만 적용될 수 있습니다.

‘아주 크게’에서는 작은 휴대전화의 요약 카드를 한 줄씩 표시하고 입력 항목도 세로로 배치합니다. 하단 메뉴는 글자를 줄이는 대신 좌우로 이동할 수 있습니다. 중요한 설명의 흐린 색을 진하게 하고 버튼·주요 입력칸은 최소 높이 48px로 조정했습니다. 체크박스는 크기를 키웠고 키보드로 이동할 때 초점 테두리를 표시합니다. 브라우저의 화면 확대도 함께 사용할 수 있으며 확대를 막지 않습니다.

## 사이트맵으로 메뉴 찾기

메뉴의 **농장 관리 바로 다음에 있는 사이트맵**을 열면 홈·농장계획·농작업일지·운영·교류·자료함·영농정보와 각 메뉴의 주요 기능을 한 화면에서 확인할 수 있습니다. 카드의 메뉴 이름을 누르면 해당 화면으로 이동합니다. 농장 관리 카드와 메뉴는 관리자에게만 표시됩니다. 참여자·열람자도 사이트맵을 사용할 수 있으며 기존 권한을 그대로 적용합니다. 모바일에서는 하단 메뉴를 좌우로 이동해 사이트맵을 선택하세요. 글자 크기 설정도 그대로 적용됩니다.


## 농장계획 한 칸으로 찾기

농장계획 목록의 목표 연도·예정 월·계획 상태·작성자 선택칸을 제거했습니다. 검색창에서 제목·내용·목표 연도·예정 기간·상태·작성자·담당자·작물·장소·실행 결과와 연결된 기록·첨부파일 이름을 찾을 수 있습니다. 띄어쓰기로 나눈 단어는 함께 일치하는 계획을 찾습니다. 예: `들깨 6월`, `관리자 완료`, `2027 토양개량`. 예정 월 검색은 시작일과 종료일 사이에 걸친 월도 포함합니다.

`완료`, `미실행`, `진행중`, `보류`, `취소`는 계획 자체의 상태를 찾으며 `미완료`는 미실행·진행중 계획을 함께 찾습니다. 목표 연도만 정확히 찾으려면 `목표연도:2026`처럼 입력합니다. 홈의 올해 계획 바로가기도 이 조건을 검색창에 표시합니다. 검색어를 지우면 모든 연도의 계획이 다시 표시됩니다. 가까운 일정이 먼저, 지난 일정은 뒤에 표시되며 CSV와 접어 둔 결과 요약은 현재 검색 결과를 따릅니다. 계획 작성 화면의 목표 연도·예정 날짜는 그대로 유지합니다.

## 운영·교류 한 칸으로 찾기

운영·교류 목록의 시작일·종료일·연결 계획·활동 분류·작성자 선택칸을 제거하고 **찾기와 CSV**를 남겼습니다. 찾기에서는 제목·내용·활동 날짜·분류·작성자·참여자·연결 계획 이름/목표 연도·첨부파일 이름을 함께 찾습니다. 예: `교육 3월`, `회의 관리자`, `2026/10/17`, `교안.pdf`. 여러 단어는 각 항목에서 모두 일치하는 기록을 찾고, 검색어를 비우면 전체 활동을 실제 활동일의 최신순으로 표시합니다. CSV는 현재 검색 결과만 내려받습니다. 활동 작성 화면의 분류·날짜·참여자·관련 계획 입력은 유지합니다.
