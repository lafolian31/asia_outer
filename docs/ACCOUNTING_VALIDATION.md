## 기기 검수의 범위

Chromium 자동화에서 PC 1440px, 태블릿 820px, 휴대전화 390px로 공동회계 업로드·조회·보고서·재로그인을 확인했습니다. 기존 가독성/사이트맵 검증에 공동회계를 포함하여 320px 및 아주 큰 글자에서도 가로 넘침이 없는지 확인했습니다. 이는 화면 크기 모의 시험이며 **실제 iPhone Safari·iPad·Windows PC 기기에서 직접 검수한 결과는 아닙니다.**

## 운영 반영 후 남은 검수

1. 실제 Supabase 조직 Free 플랜·남은 DB/전송량과 운영 RLS/RPC 확인.
2. 관리자/총무/일반회원 세 운영 계정으로 가상 소량 거래 시험, 비로그인/접근 해제 사용자 차단 확인.
3. 비공개로 확보한 실제 카카오뱅크 XLSX/XLS에서 제목행·일시·입출금·잔액·고유번호 열 연결과 은행 원본 합계 대조. 비밀번호를 앱에 입력하지 않기.
4. 실제 iPhone/iPad/Windows에서 파일 선택·클립보드·엑셀 다운로드·큰 글자·키보드 조작 확인.
5. 공식 카카오뱅크 링크가 사용자 기기에서 정상 열리는지 확인. 계좌 직행 링크나 은행 자동 로그인은 제공하지 않음.
6. 운영 전체 백업을 비공개 보관하고 별도의 빈 프로젝트에서 복구 절차 확인.

회계 원본은 가져온 파일을 은행이 발급했는지 진위 검증하지 않습니다. 담당자가 실제 은행 내역과 대조해야 합니다. 개인정보 마스킹은 완전한 이름 인식이 아니며 계좌번호 변경/영수증 첨부/대용량 보고서의 제약은 [운영 안내](ACCOUNTING.md)에 있습니다.
